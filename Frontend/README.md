## 🚀 Cara Menjalankan

1. **Buka Langsung di Browser**:
   Cukup klik dua kali pada file `index.html` untuk membukanya di browser favorit Anda (Chrome, Edge, Firefox).

2. **Gunakan Live Server (VS Code)**:
   - Klik kanan pada `index.html`.
   - Pilih **"Open with Live Server"**.
   - Halaman akan berjalan di `http://127.0.0.1:5500/Frontend/index.html`.

3. **Uji Koneksi ke Backend**:
   - Pastikan backend sudah berjalan (`php artisan serve` di folder `Backend`).
   - Tekan tombol **"Kirim Request"** di halaman frontend untuk menguji respon API secara langsung.
